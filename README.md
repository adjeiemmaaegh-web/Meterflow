# MeterFlow Mobile

Mobile-first React and TypeScript water-meter forecasting PWA for 335 apartments across Blocks A–G. Historical readings are **not** committed to this repository.

> Engineering status: React 19 production build and real-device PWA/IndexedDB validation remain pending. Do not treat the application as a verified public production release.

Source files and development documentation are being imported into this repository. Personal meter datasets must remain local to the user's device.
